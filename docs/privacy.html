Privacy Policy for FileGrid

Last Updated: October 2026 | Effective Date: October 2026

Overview & Commitment

FileGrid ("we", "our", or "the application") respects your personal privacy and is fundamentally engineered around zero data collection. This Privacy Policy details our operational commitments to privacy, data minimization, and local execution.

1. No Collection of Personal Information

FileGrid is a 100% local desktop file management tool:

  • We do not collect, transmit, harvest, or sell any personally identifiable information (including your name, email address, physical location, IP address, device identifiers, or usage logs).
  • We do not embed telemetry packages, behavioral analytics, advertising SDKs, or background tracking mechanisms.

2. Local Data Processing & Storage

All file browsing, directory navigation, file operations (copy, move, rename, delete), image previews, and layout configurations execute strictly in-memory and on your personal computer:

  • File contents and folder metadata never leave your device.
  • Application configuration preferences, customized bookmarks, and session states are persisted solely in your local user profile directory (%LOCALAPPDATA%\FileGrid).

3. Network & Internet Access

FileGrid operates fully offline for all core file management functions:

  • The core application does not connect to external servers or transmit heartbeat requests.
  • Any user-initiated check for updates simply queries official release metadata upon explicit manual click, without transmitting personal identifiers.
  • Optional plugins (such as media visualizers or downloaders) communicate exclusively with user-designated endpoints upon explicit user command.

4. Third-Party Services & Advertising

FileGrid contains zero third-party advertising SDKs, zero ad networks, and zero tracking pixels.

5. Children's Privacy

Because FileGrid collects no personal data whatsoever from any user, it is fully compliant with child privacy standards (including COPPA and GDPR-K) and is safe for users of all ages.

6. Contact & Support

If you have any questions regarding this Privacy Policy or FileGrid's data protection practices, please contact us at:

  • Repository / Issue Tracker: FileGrid on GitHub
