# FileGrid

A modern, high-performance dual-pane file manager for Windows built with WinUI 3 and .NET.

## Overview
FileGrid is commercial proprietary software designed for power users who demand lightning speed, keyboard-driven navigation, instantaneous directory listing, zero telemetry, and deep Windows shell integration.
